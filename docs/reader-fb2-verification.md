# 第二阶段 B1：FB2 / FBZ 实施与验收

日期：2026-09-18
状态：格式代码/API闭环已实现；真实原版浏览器验证仍待既有环境确认，不能宣称整个阶段已完成。

## 本批范围与决策

- 接入 .fb2、.fbz、.fb2.zip。后两者以FBZ容器类型保存，原始上传名称和字节保留，未改后缀冒充EPUB。
- 直接依赖 fast-xml-parser 5.11.1（MIT），固定在package/lock；原来已由EPUB依赖安装，本次显式声明。检查本地许可证和固定接口，不引入ReadAny业务代码。
- 固定foliate-js仍负责分页、字体、位置、CFI和原生blob章节加载。FB2是结构化XML而非固定版式：本项目从经过校验的语义模型生成XHTML，保留结构和资源，但不承诺印刷页版式。
- 未直接启用上游未经校验的其他格式makeBook入口。服务端和客户端共享同一个有序XML/正文模型，确保canonical段落、章节href和显示段落标识一致。
- 编码支持UTF-8、带/不带BOM的UTF-16LE/BE、windows-1251、windows-1252/iso-8859-1（WHATWG解码语义）。损坏字节、冲突声明、非法XML字符拒绝，不能靠替代字符冒充精确来源。
- 数字实体及五个XML实体解码一次；CDATA和已转义实体不二次解码。命名空间用无原型映射及own-property检查。
- 保留封面/嵌入PNG/JPEG/GIF/WebP、正文、分级章节、表格、诗歌、加粗/斜体/上下标、脚注及反向引用。普通第二body仍连续阅读，只有明确notes为非线性。
- 生成小节导航ID不进入原文件链接映射，悬空原引用不能被意外修复。图片型章节保留，但没有文字来源就不伪造句读，也没有OCR。
- 复用概念/句读历史/引用浮窗、多段选文和1000 Unicode字符上限。跳转与首次选文使用相同FB2段落选择器，不只映射普通p。
- 书架旧导入页面不再无论成功失败都直接刷新；JSON/格式/连接错误明确显示，保留已有书籍并允许重试。

## 安全与资源

- XML最大24MiB；层级128；解析构建阶段限制元素数量，转换再检查总节点20万；canonical最大800万UTF16单位。
- 禁用DTD、自定义实体与外部实体；未知正文标签、非法嵌套、未归属段落文字明确拒绝，不能静默丢正文。
- 嵌入图片MIME/字节签名核验；单图8MiB、合计16MiB。原书外部图片、SVG与未支持类型明确拒绝；图片只转换为本书拥有的blob URL。
- 外链只允许http/https/mailto地址进入可预览模型，阅读器仍不自动访问；javascript/file等拒绝。
- FBZ只接受一个FB2文件加可选目录，不猜多个文档、不忽略额外资源；所有字节均在内存解压，不按归档路径写磁盘。
- ZIP结构、重复路径、压缩比、条目总量、实际输出、CRC、重叠和EOCD歧义都检查。FBZ不要求EPUB mimetype，但默认EPUB仍完整保留原检查。
- app-owned bridge对非空文字Range规范Text端点后交CFI工具，只有全文相同才接受；不改原Range或正文、不改上游CFI和渲染源文件、不改closed shadow root或运输。collapsed/图片Range仍保持原契约。
- Foliate固定上游14文件校验通过；本批新增的桥接行为位于本项目自有bridge，并有真实固定版CFI回归。PDF资源3项完整性回归通过。
