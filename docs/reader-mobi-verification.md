# MOBI / AZW / AZW3 候选评估与阶段门禁

更新日期：2026-09-20
状态：**未开放生产导入；第二阶段此批次未完成。**

## 更正 2026-09-18 的临时结论

此前原型把同一个合成 MOBI6 文件分别命名为 `.mobi`、`.azw`、`.azw3`，只能证明扩展名分发和保存流程，不能证明 KF8/AZW3 内容可解析。该原型还存在目录标题用子串猜测、首记录预检不完整及主线程同步解析的风险。

2026-09-20 已撤回未经完整验收的生产 adapter、上传白名单、存储白名单和 UI 格式宣传；API 对这三类文件返回明确 415“正在验收，尚未开放导入”，不写书籍/章节/原件。保留候选研究模块与测试，不删除任何既有用户数据。完整 MOBI/AZW/KF8、原版资源和定位的阶段目标没有取消，也没有将“拒绝导入”当作格式交付。

## 当前可核验证据

### 容器预检（应用自有代码）

- 识别 PDB BOOK/MOBI、严格递增记录目录和当前 record 内边界。
- 按真实头版本识别 MOBI6/7 与 KF8，解析有界 EXTH，复核双格式 BOUNDARY/次头。
- 两个 PalmDOC 头均检查加密；DRM 字段不是仅凭文件后缀推断，不进行解密。
- 限制声明的正文/记录/头部数量和大小；这些预检不能代替下游实际解压/内存预算。

### 可终止的候选解析进程

- `mobi-parser.ts` 不再在 Next Web 主进程调用第三方同步解压；由独立 Node 子进程完成候选解析。
- 父进程拥有截止时间和 AbortSignal，实际终止同步死循环；收到 IPC 也必须等进程 close，随后才清理本次私有目录。
- 输入快照在首次 await 前复制；IPC 通过显式类型守卫、章节唯一 ID 和累计输出上限复核。
- 子进程不继承模型密钥或 NODE_OPTIONS，Node 文件权限只允许读依赖/worker及读写本次临时目录。
- V8 old-space 192 MiB 是堆预算，**不是 RSS、ArrayBuffer、磁盘或网络的完整 OS 沙箱**；不能据此宣称所有资源攻击都已解决。
- 子 agent 发现父进程旧 HTML 正则可被 64 KB 未闭合标签阻塞 2.5–6.9 秒；已将全部 HTML 解析/清洗放入 worker，使用固定开发依赖 `parse5@8.0.1`，父进程只验证有界的纯文本段落数组。该真实多记录恶意输入回归保留，不能用延长超时替代修复。
- 目录标题通过真实 `resolveHref` 解算，不再用 `href.includes(id)` 猜章节；正文与标题同文也不删除。
- MOBI 文本候选直接读公开 spine，避免为了提取文字写图片；KF8 原版资源保真、持久资源模型仍未完成。
