# 句读选项与 Agent 最小单位分块（2026-09-29）

## 确认范围与实现

- 新增顶部“句读 · 选项”，与“Aa · 选项”相邻。集中句读方式、解读方式、回复长度及阅读增强；选文工具栏和聊天加号菜单移除重复设置。
- “按句意细读”默认，以完整句子为最小单位；“整段句读 · 原有”以自然段为最小单位。两种模式允许 Agent 合并紧密关联的连续单位，不要求一句/一段必成一块。
- 分割规则和示例仅放在 `plan_reading_units` 工具描述。不预分句，不增加粒度评分、句数/字数限制或复核 Agent；保留结构解析、完整来源与资源上限保护。
- 追加“小白”档位，补必要背景、解释术语并举例；与通俗/正常/深入、回复长度分别独立，按书保存，修改仅影响下一次生成。
- “查看本节句读”悬停/聚焦/触屏点击展开浮窗，提供查看历史和按当前设置重新句读。重做先确认，不另加常驻按钮，不删除历史。
- 原文与细分句读各有关键词标黄、关键句下划线开关。原文默认关，解释默认开。原文重点来自 Agent 的逐字来源，不用本地推测；结果重点使用 Agent 保存的 emphasis。
- 开关仅控制显示。新句读同步保存重点；旧书或旧结果可明确点击“生成本节重点”，只生成重点，不新增假句读记录。显示模型用量，失败保留旧标记。
- EPUB/精读/PDF 文字层沿用非侵入 Highlight 图层，原文节点不变；句读卡片来源只添加展示层标记。无 OCR，缺文字映射不猜位置。
- 分块格式失败明确说明尚未生成，原有句读线属于历史；合法二次 JSON 仅无损解码，损坏 JSON 不修补、不静默降级。

## 数据与安全

新增 `source_emphasis` 表，范围绑定 edition/paragraph，保存与读取都核对逐字原文。每块的解释、标注与重点在同一事务内保存。单独重点接口从服务端读取章节，拒绝伪造正文、错书、错章和未配置模型；服务端错误不回显密钥。
