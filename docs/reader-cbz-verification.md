# 第二阶段 B2：CBZ 图片阅读实施与验收

日期：2026-09-18
状态：CBZ 代码、API、生产构建和隔离浏览器验收通过；第二阶段整体仍未完成。

## 已实现

- 支持 .cbz 导入；只接受包含图片页和允许的元数据文件（ComicInfo.xml、.DS_Store、Thumbs.db、__MACOSX）的归档，不执行XML，不接受SVG、HTML、脚本、PDF、嵌套压缩包或未知扩展。
- 图片页按自然数字顺序排序，不把文件名数字强制转Number；支持长数字、前导零、Unicode文件名和重复文件名拒绝，页数上限1000。
- PNG/JPEG/GIF/WebP 通过 sharp 真实解码、容器尾部/RIFF长度、MIME与扩展名、尺寸和像素上限校验；单图24MiB、总归档沿用ZIP安全边界；动画图片拒绝，不重编码原始字节。
- 服务端保存原始CBZ和SHA-256，图片接口按 bookId + editionId + 页码和 chapter sourceHref 严格绑定，只交付核验后的单页图片，不暴露任意ZIP成员。
- 原版图片阅读器支持页码、目录、上一页/下一页、PageUp/PageDown/Home/End、LTR/RTL、适合整页/适合宽度、25%–300%缩放、位置恢复、旧Blob撤销和请求取消隔离。
- CBZ没有文字层：精读按钮禁用，概念开关禁用，明确提示“OCR尚未启用”，不伪造文本来源、概念或句读。

## 安全决策

- CBZ复用现有ZIP结构、EOCD歧义、路径、压缩比、实际解压、CRC和条目重叠校验；目标页按需读取，但导入时完整校验所有图片页。
- 不把图片OCR、文件名或元数据当作正文，不写入paragraphs，不开放AI句读。
- 原始图片通过本地Blob展示，主题色不反转原图，不用Next图片处理重编码；图片接口的Content-Type、尺寸头和版本哈希都经过服务端核验。

## 验证证据

- CBZ 子 agent 独立验收：6个测试文件110项全部通过；CBZ模式/原版装配回归8个测试文件132项全部通过；ESLint与TypeScript通过。
- 本地API测试：导入、自然页序、原始图片字节、错误页码/版本、完整性元数据损坏共8项通过。
- 隔离生产端口3295实际浏览器验证：
  - 生产页面导入的2页CBZ显示为真实图片；
  - 原版模式可见，精读按钮禁用并显示OCR提示；
  - 下一页、目录定位、200%放大与横向滚动、刷新后页码和缩放恢复均通过；
  - 未调用模型，未使用正式data。

## 未证明与限制

- CBZ图片原版已实机通过，但复杂漫画阅读体验（双页布局、右到左整本自动翻页、漫画气泡OCR）尚未实现；当前RTL只改变方向键语义，不改变页码顺序。
- 没有OCR、文字搜索、概念浮窗和句读历史标记；这是图片无canonical文字来源时的明确能力边界，不是漏做。
- 尚未支持MOBI/AZW/AZW3、UMD转换；EPUB/FB2原生Foliate实机视觉确认仍待此前环境问题确认。
