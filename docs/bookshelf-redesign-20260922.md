# 书架减法与识别效率改造（2026-09-22）

## 实现范围

- 书架助手默认收起，可展开并持久化偏好。只隐藏面板，不卸载会话，不取消生成；阅读页保持双栏。
- 书架不再重复左侧书籍树；返回阅读页仍可切书、切版本和浏览目录。
- 书卡主层只展示封面、显示书名、作者、格式、阅读入口与已知位置。
- 原始书名/文件名、BookID、EditionID、版本选择和下架操作保留在原生 details 内；支持键盘与 Escape 收起。
- 显示书名单独保存到 book_display_titles，支持恢复原名，不修改 books.title、原文件、版本或标注。
- EPUB 栅格封面、PDF 首页按需生成成最大 320×440 WebP；浏览器懒加载、同源接口、内容指纹缓存、串行生成及文字兜底。封面不阻塞导入流程；无原件的旧版本不伪造封面。
- 最近阅读摘要绑定 BookID 和 EditionID；未知位置显示“已打开，尚未记录位置”，不猜页码和百分比。原始位置恢复仍使用原有锚点。
- 搜索支持显示名与原始文件名；新增格式、阅读状态筛选及最近阅读/导入/书名排序；网格和列表共享同一组原始书籍身份，不按标题合并。
- 控件/详情圆角分层、低对比边界、键盘 focus-visible、列表和窄屏布局。

## 决策

- 保留所有同名书籍及历史，不自动去重。
- 不向第三方请求私人文件封面；不把 SVG/HTML 作为封面直接输出。
- 不为内置浏览器验证差异更改 EPUB 运输、shadow root、依赖或安全策略。
- 未追加新的依赖。复用已有 EPUB、PDF.js、sharp 及 ZIP 安全核验。
