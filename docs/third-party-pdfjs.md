# PDF.js 固定依赖与第二阶段边界

- npm 固定版本：pdfjs-dist 5.4.296（既有依赖，不追随运行时CDN）。
- 许可：Apache-2.0；LICENSE 随本地资源置于 public/vendor/pdfjs/LICENSE。
- scripts/vendor-pdfjs.mjs 从安装的固定包同步worker、CMap、字体、wasm、ICC和图标，版本不符时停止，不下载不明构建。
- 主线程按需加载同版本npm模块；worker及字体资源同源，不向第三方发送书籍。
- PDF脚本、XFA、表单和附件交互不启用，外链只提示；页内/目录跳转通过受控linkService核验页数。
- 新导入按pdf:page:n建立来源，每页保留准确文字序列。旧版仅在整体非空白序列完全一致时生成映射，不重写旧段落ID；不一致不猜位置。
- PDF中NUL代表无法识别的字符，Node SQLite读取TEXT会在该处截断；导入、索引、文字层一致替换为明确的�，原文件Canvas不改，不能猜公式语义。
- 纯扫描PDF保留原件并显示无文字层提示；不假装已经OCR。
- 索引页数上限5000、文字总量800万UTF16单位；虚拟页面只渲染视口附近，每画布最多800万像素，DPI最多2。
- PDF的文字项顺序仍取自文档文本层，不宣称对所有复杂多栏PDF都已重建正确语义阅读顺序；复杂格式兼容仍需真实样本验收。
- 原书AnnotationLayer与应用AI/手动标注是不同来源。应用标注和知识回跳复用多片段契约。
