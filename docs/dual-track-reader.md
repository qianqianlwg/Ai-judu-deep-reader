# 双轨阅读器：两阶段实施与验收

> **当前状态更新（2026-09-16 18:03）：** 用户要求撤销为内置浏览器增加的兼容改动，现已移除 srcdoc 运输及 open shadow root 补丁，恢复原生 blob / closed shadow root。以下第一阶段“通过”是撤销前的历史验收记录，不代表当前原生渲染已经通过。真实样本导入成功，但本次内置浏览器重试仍超时；按用户要求暂停并等待环境确认，未继续添加兼容方案。详见 `reader-followup.md`。

## 范围

保留“原文件阅读表现层 + AI 文本索引层”，不是把现有段落、标注和 Agent 替换为一个阅读控件。第一阶段交付 EPUB 原版阅读，第二阶段交付 PDF 原版和额外格式；未经验收不宣称整个双轨项目完成。

### 第一阶段（本次）

- 原文件持久保存、字节哈希和大小、版本绑定、增量迁移；旧书架/会话/手动标注不被改写。
- 独立 DocumentAdapter 文本提取边界，EPUB/PDF/TXT/MD 原有文本链路可用。
- 同源、版本校验的原文件读取接口，不公开磁盘路径，不把书籍 HTML 当可信应用代码。
- 官方 MIT foliate-js 固定版本，用于 EPUB 原版阅读。保留内嵌图片、CSS、SVG/MathML、目录、脚注；对不可信内容禁脚本、网络、表单、嵌入及越界资源。
- 原版/精读视图切换，章节导航、位置恢复；原版选文与现有 canonical paragraph+UTF-16 锚点精确桥接。
- 原版能够发起句读、保存手动标注；已保存标注/知识/引用回跳有可验证的原文位置。不能精确映射时明确反馈，不能静默猜位置。
- 旧导入没有原文件时继续精读，不伪造原版可用状态。不存在的原件、损坏文件有可恢复界面提示。
- 同级单元/集成测试，全套测试、严格类型、lint、隔离构建/端口实际验证；独立子 agent 逐项验收。

### 第二阶段（后续）

- PDF.js Canvas + TextLayer + AnnotationLayer 原版阅读；页码/坐标/文本与 canonical 段落关联、缩放及跨页选区。
- 原版/精读模式切换，扫描 PDF 与 OCR/视觉能力诚实分离（不把可显示当可文字检索）。
- 按格式能力扩展 FB2/FBZ、MOBI/AZW/AZW3、CBZ、UMD→EPUB；TXT/Markdown 保留现有精读链路。
- 更多格式统一 locator、迁移/重导入策略、性能/安全/真实书籍回归和子 agent 验收。

### 安全复核闭环

- 在服务端调用旧 EPUB parser **之前**，对原始归档结构、路径、条目数、单条/总解压大小与压缩比进行校验；逐条异步 zlib 解压设置原生 `maxOutputLength`，核对实际字节数与 CRC，不能仅相信文件头。保证预检和旧 parser 的结束记录一致，拒绝有歧义的归档。
- 正常 EPUB/DEFLATE、常规 ZIP 注释保持通过；高压缩、虚报尺寸和有歧义归档的单元/API 回归均通过。真实 3277 HTTP 验证均返回 422 JSON 且无原件残留。
- `srcdoc` 不支持带前缀 XHTML；明确拒绝，并在最终 HTML 解析后复核实际 head 中的 CSP 位置。完整净化链路 15 项专项通过，独立复核已关闭该问题。

### 明确边界

- 第一阶段原版只启用 EPUB；PDF/TXT/MD 保留文本精读和原件，不表示 PDF 已有原版渲染。
- 不提供 OCR、DRM 解密、任意损坏 EPUB 修复或所有阅读系统的排版一致性保证。
- 精确桥接只支持可核对的单段正文；跨段或净化后无法核对的内容明确提示切回精读，不猜锚点。图片/复杂内容仍可原版浏览。
- 暂不支持字体混淆/加密 EPUB；严格 XML/UTF-8 和安全 CSS 子集可能影响少数书籍样式。详细许可、固定 commit、补丁与格式边界见 `third-party-foliate.md`。
- 原版位置在本浏览器按版本/文件哈希保存；不承诺跨设备同步。真实个人 EPUB 测试尚未提供，不以合成样本替代所有真实书籍兼容性。
