# UMD 转换版阅读接线与验证

日期：2026-09-20。范围：已保存 UMD 版本的转换版 UI、渲染文件身份、位置与精读来源；公开上传仍保持 415。不是完整第二阶段完成报告。

## 已实现

- `resolveConvertedEpub` 核对选中版本、原件与转换元数据、连续章节资源和可用正文。读取地址只由书籍/版本ID生成，失败有明确原因，不将 UMD 原件交给 EPUB 解析器。
- 阅读组合根把有效 UMD 派生物交给既有 EPUB/Foliate 通路。模式按钮、阅读器名称、翻页和提示标为“转换版”，说明转换版不代表原文件版式；原 UMD 下载单独提供。
- 读取 `/converted` 的实际字节在客户端再次核对大小与 SHA-256，再交给 `loadEpub`。不把派生哈希覆盖到原件元数据，也不为校验失败添加旁路。
- 转换位置使用 `judu:converted-position:<editionId>`，记录独立角色、来源哈希、派生哈希和转换器版本。不读写原版位置键；旧派生哈希、原件哈希或转换器不匹配时不复用CFI。
- CFI仅做有界封装检查，实际定位由当前书的Foliate复核。没有自建另一套CFI语法解析器；原有原版位置契约不变。
- 生成EPUB继续使用原UMD同一解码快照生成的canonical正文；概念、句读、选文和引用沿用现有交互组件，1000字上限不变。

## 已取得的证据

- 上游627字节UMD与含字面实体、emoji/增补汉字、同文标题、重复正文的自造UMD，分别经真实worker、转换、双份存储、派生哈希验证和ZIP读取；所有生成段落能建立DOM Range，并回到所属canonical段落。重复导入得到独立版本/位置键，旧段落ID不能定位到新版本。该测试不是Foliate分页视觉验收。
- 首轮全量172文件2660项通过，无跳过；lint、严格类型、生产构建通过。
- 3302隔离生产服务：首页/书库/两份下载、CSP、跨版拒绝、私有worker不可读与UMD上传门禁共16项检查通过。两个版本的实际HTTP响应另外通过客户端公开元数据守卫、派生字节校验和位置身份检验。
- 使用独立 `.next-verify-umd-ui-20260920` 和 `.verify-umd-ui-20260920/http/data`，没有向正式data写测试书籍，没有调用真实模型。

## 未完成与环境边界

- 未开放UMD上传：现有代码接线不代替真实阅读验收。仍需公开导入契约、更多独立合法样本、封面/漫画/混合型的分项兼容性验收。
- EPUB/FB2此前的重新加载超时及自动化工具不能点击closed shadow root仍待环境确认。本批不重试该浏览器问题，不改blob/srcdoc、上游shadow root或安全策略来绕过。
- 不能把DOM/组件/API测试当作Foliate浏览器分页、悬停或来源回跳的视觉验收。MOBI/AZW/AZW3及UMD剩余矩阵继续属于原第二阶段目标。

## 独立验收发现、修复与最终结果

独立子agent的9个异步探针首轮复现5个失败：旧锚点/翻页失败污染新会话、旧定位成功覆盖新派生位置、旧CFI初始化失败重试已关闭view，以及旧初始定位迟到把目录切回已关闭会话。不是将绿测等同于无缺陷；本批已经逐项修复。

- 所有异步提交结果和保存位置核对会话归属；锚点导航额外核对请求序号。过期错误记录日志，但不改新版本UI、不写新位置、不重试已关闭view。
- 9个探针迁入同级永久测试，另补旧目录失败与同会话旧锚点失败，共11项。子agent独立复验9/9和3文件106/106通过、0跳过、源码测试前后一致，确认此前阻断关闭。
- 最终全量 **173文件2671项通过、无跳过**；lint、严格tsc、生产构建再次通过。生产自测3303重新完成16项HTTP检查及2个版本客户端身份闭环；这些仍不冒充浏览器视觉证据。
- **3302/3303均已释放。主项目已重启3000、默认.next、正式data**，首页、/api/library、/api/books均200。正式库13张业务表的记录摘要与重启前一致：3书/3版本/5条AI标注/2条手动标记/2会话/8消息；未新增UMD测试书到正式库。
- 本批未操作已暂停的Foliate浏览器问题，公开UMD上传仍415，整个第二阶段保持未完成。
