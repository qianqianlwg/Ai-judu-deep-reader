# 书架下架与恢复（2026-09-21）

## 行为与设计
- 书卡提供“下架”入口，展开明确确认说明，取消不会发送写请求。
- 下架以 BookID 为单位包含所有版本，同名不同 BookID 不受影响；仅写入独立 book_shelf_state 元数据表。
- 不删除或改写书籍、版本、原文件、章节、标注、笔记、对话和向量索引。
- 默认 /api/library 和 /api/books 隐藏已下架书籍，/api/library?shelf=archived 提供恢复列表。
- PATCH /api/books/[bookId]/shelf 接收严格 boolean archived；下架和恢复均幂等，未知书籍 404。
- 工作台书架与独立 /library 页均有确认下架和“已下架书籍 → 恢复上架”。网络失败明确反馈，忙碌状态禁用操作。
- 当前正文和聊天不强制关闭，但当前书不再作为空书架兜底复活；下次启动只恢复在架书籍。
