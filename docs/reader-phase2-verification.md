## 实现范围

- EPUB 与 PDF 使用共用 OriginalInteractionLayer、AnnotationPopover、ConceptPopoverContent 和 HistoryPopoverContent。概念定义、句末历史标记、完整句读入口和引用卡片与精读保持同一交互设计。
- 浮层不改书内正文节点，不改 CFI，不打开 Foliate closed shadow root，不替换其 blob 运输。
- PDF.js 5.4.296 同版本主线程与本地 worker/CMap/字体/wasm/ICC/图标；无运行时 CDN。
- Canvas 原页、TextLayer 真文字选区、受控 AnnotationLayer；页码、缩放、旋转、文档目录和按原件 hash 保存位置；可见邻页渲染，限制画布像素。
- 新导入按页建立文本索引；旧索引仅整体非空白字符精确一致才衔接，不重写历史 ID，不模糊命中重复文本。
- 跨页选文、五色手动标亮、概念和 AI 下划线分层，整个原生选区最多 1000 Unicode 字符；不会自动拆分成多次句读。
- PDF 原件中的 NUL 会使 SQLite TEXT 读取截断。导入、页索引和文字层统一保留为明确未知符号 �；原件图像不改，不猜公式。
- 图层采用上游要求的 scale-round-x/y 和 userUnit；异步 AnnotationLayer 先在独立节点完成，迟到结果不能污染新缩放；Canvas 取消承诺立即收接。
