# 阅读交互、模型选择与向量搜索（2026-09-21）

## 实现
- EPUB、PDF、文字版共用选文释放门控：拖选中不弹菜单，松开指针后提交；保留键盘选文，处理取消与 iframe 外释放。
- 引用的 EPUB 内部地址放入默认折叠的“定位详情”；来源跳转不变。
- AI 设置支持每行/逗号填写多模型，同一网关、协议、密钥；聊天选择框常驻。请求带模型名，服务端白名单校验并保存到消息/重试快照。
- 左侧导航桌面折叠至 44px，可恢复且本地记忆；手机导航保持原抽屉逻辑。
- 独立 SiliconFlow Qwen/Qwen3-Embedding-8B 配置，固定官方 HTTPS 地址，1024 维。
- 本书手动索引：明确外发授权，每批 8 个切块，每块最多 1200 Unicode 字符；SQLite 保存向量，按版本、模型空间和文本哈希隔离。跨进程租约避免重复建索引；可暂停和断点续建。
- 搜索提供本地关键词、语义、关键词+向量三种方式。当前是本地精确余弦检索与 RRF 融合，不是 pgvector/ANN；大书库后续可优化。结果保存真实 UTF-16 原文偏移。
- 不自动上传或索引正式书籍。密钥仅保存在服务端本地数据库，不进入源码、前端响应或浏览器存储。
