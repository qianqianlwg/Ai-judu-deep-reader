# 随阅读生长的思维导图

## 产品与技术决策

- 一本书一张思维导图，只根据已完成句读的选文持续更新；不提供全书补全，也不读取未句读正文。
- 使用 `wanglin2/mind-map` 的 `simple-mind-map` JS 核心，固定版本 `0.14.0-fix.3`。默认沿用上游矩形节点、逻辑结构布局；浅灰画布、白色浮动工具栏参考其 Web 应用。
- 主入口是可平移、缩放、双击编辑和拖拽换层级的画板，提纲是辅助视图。不搬入 Vue2/ElementUI 应用，也不再保留 React Flow/Dagre 原型。
- AI 可以修改用户编辑的节点及结构，不设所有权锁；所有内容和结构变化统一存快照，支持撤销、重做及历史恢复。
- 左侧导航“思维导读”和阅读工具栏“导读”均可进入；原文及句读依据可跳回对应书籍版本和会话。

## 数据与运行机制

1. `guide_sources`：已完成句读的不可变选文快照与队列状态，保留 book/edition/thread/message/anchor 身份。语义句读按已完成子块入队，排除父汇总消息、普通追问、失败和未完成消息。
2. `guide_revisions`：AI/手动修改的完整树快照、原因、时间和AI用量。`guide_outlines` 保存当前版本、当前快照及重做栈。
3. 句读完成和来源入队在同一短事务中提交，使用 attempt 核对；重新播放同一消息不重复消费。
4. 后台 worker 不依赖导图页面打开。持久化队列、每书租约、旧 worker 隔离及乐观版本检查保证重启与并发编辑安全。模型网络调用在事务外；发生用户并发编辑后，AI会基于新版重新整理，而不是永久禁止改动用户节点。
5. 模型工具只有现有节点分页/搜索、已句读来源读取和增量更新；不提供书籍全文或外部搜索工具。
6. 图库 UID 对应领域节点 ID。图库只回传标题、层级、次序、位置；归纳和来源在领域层保留，不接受图库 JSON 重写原文依据。
7. 编辑、拖动和保存期间不应用后台轮询，防止旧树覆盖草稿；离开画板冲刷防抖，关闭页面前提示未保存变更。版本冲突明确反馈。
8. 折叠和视角是按书籍保存在浏览器中的偏好，不产生内容版本。视角只恢复有限数值字段。来源分批读取，不在100条时截断。
9. 历史面板显示最近60次修改，历史快照不因展示上限删除；仍可继续撤销到早期版本。恢复旧版也可撤销。
10. 树校验、子树查找及移动坐标清理使用迭代遍历，不为每个节点重复遍历整个子树，不额外限制AI的合法层级。

## 上游接入与许可

文档：https://wanglin2.github.io/mind-map-docs/

- 只加载 Drag、TouchEvent、KeyboardNavigation、MiniMap、Export；不注册 RichText、Formula、Cooperate 或任意HTML节点。
- 使用 `updateData`，不使用会清空内核历史的 `setData`；原生 `BACK/FORWARD` 命令接入服务端版本历史；卸载调用 `destroy`。
- 发布包未附带所声明的类型文件，使用项目最小严格类型接口与加载边界校验，不传播 `any`。
- 局部 override 将 simple-mind-map 的 uuid 固定到 `11.1.1`。npm audit 仍报告未加载的 Quill 低危告警，以及原项目既有的 Vitest/brace-expansion 告警；未强制升级无关依赖或倒退图库。
- 保留 MIT 许可全文 `docs/licenses/simple-mind-map-LICENSE.txt` 和页面致谢；固定版本应对上游低维护状态，后续升级须重新跑画板交互验收。
