## 实施内容

1. 原版 EPUB 与精读支持多段选文，按原书顺序保存所有来源片段，保留 UTF-16 偏移与旧单段兼容。
2. 可见选区最多 1000 字，正/反向拖选、键盘选取和跨段总长度使用统一 Unicode 字数规则。超过上限明确提示；提交超长请求直接拒绝，不调用模型、不自动分段。
3. 操作栏显示总字数、段落数和完整原文预览。跨页以“继续选取”明确合并，同次拖选更新不丢失前页来源，下一次普通划选清除旧扩展。
4. 句读普通/流式请求、服务端校验、保存工具及兼容自动保存、历史恢复、编辑和重试均保留多段来源。
5. 服务端验证同版本、正文范围、准确文本、顺序及连续性，拒绝跨书/跨版、跳段、篡改、代理对截断。
6. 手动标注保存全部锚点；历史/知识卡片/段落标注回跳恢复完整来源。仅部分 annotation 保存成功时仍从明确 messageId 读取完整消息来源。
7. 无效新选区清除旧快照；显式损坏的多段来源不降级成旧单段。真正没有来源的旧消息维持原兼容行为。
8. 精读来源高亮采用非侵入 Highlight 层，不拆装正文来改变原生 Range；标注/概念导致文本节点变化时重绑高亮。没有修改 foliate 的 blob 运输或 closed shadow root。
