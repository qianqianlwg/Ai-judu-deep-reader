# 每本书独立继续阅读（2026-09-21）

## 根因与修复
- 已有正文锚点使用 judu:position:BookID:EditionID，原版阅读器位置也按 EditionID 保存，不是只保留最近一本。
- 原书架标签只看 currentBookId，因此切书后上一本的“继续阅读”变回“打开阅读”，误导用户认为记录丢失。
- 改为读取每本书自己的 judu:edition:BookID；所有读过的在架书都可同时显示“继续阅读”，并显式打开上次阅读的版本。多版本书附上次阅读的文件名。
- 沿用现有本地记录，无清空、重置或迁移位置。不存在/不属于该书的缓存版本不冒用；浏览器存储失败明确反馈。
- 同页更新事件和跨标签 storage/focus 同步记录，无轮询。
- 独立 /library 书卡链接携带 BookID 与本书的 EditionID；初始化优先尊重点击的书，验证版本归属，不再被最近一本覆盖。链接意图消费后清除对应查询参数，后续刷新不跳回旧链接目标。
- 从独立书架点击进入时直接显示阅读区，不沿用上次“书架”视图。
