# 思维导图时间线排序

## 默认规则

- 同级分支按最近一次内容生成时间从旧到新排列，不按标题、节点尺寸或来源原文的位置排序。
- 节点新增、AI更改标题/归纳或补充真实来源会记录新的内容时间；仅排版、拖动结构、缩放或重新排序相同来源不更新时间。
- 深层节点更新时，将整条祖先分支排在同级最后，保留父子关系；不是把所有节点拍平成一条列表。
- 同批变化保持稳定顺序。普通手动编辑不冒充新一次AI解读。
- 画板、提纲和提纲导出共用同一套顺序。自动布局只计算坐标，不能重新打乱时间顺序。
- 默认时间线不使用自由拖拽坐标覆盖上下顺序。旧坐标仍保留于记录，不删除；画板仍支持平移、缩放、节点编辑及结构拖动。
- “定位最新 ↓”会找到最近生成或AI补充的节点，展开其祖先并移到画板中心；轮询新内容不会自动抢走用户当前视角。

## 存储与兼容

- timeline 是服务端版本元数据，包含 created/updated 顺序和 createdAt/updatedAt 时间；不属于Agent或用户内容工具的Schema。
- 每次真实导图版本事务记录内容时间，完成后才发布最新版本。
- 原有快照没有时间字段时，依据真实版本祖先链恢复首次创建及AI内容更新时间；不根据标题、布局或关键词猜测。
- 恢复过程只读，不重写旧快照。只缓存当前版本的结果，返回副本，避免轮询反复扫描全部历史以及无界缓存。
- 撤销、重做和历史恢复沿用对应版本的时间顺序，不制造新的AI句读内容。
- Agent上下文仍只包含业务内容字段，不增加需要模型提交的时间或排序参数。
