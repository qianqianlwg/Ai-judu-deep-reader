## 与宽松候选不同的决策

- 小端 magic、section/data 长度按真实输入核验；严格边界不能证明一个合法EOF文件在历史上从未被修改，具体profile限制见最终验收。
- 不忽略未知块/标志；保护或授权相关字段语义未确认前明确拒绝，不尝试解密或丢弃。
- 文字型候选用正文索引表校验压缩块的成员完整性，并按正文数据块物理顺序拼接；0x81不是排序表。元数据、数据 ID、标题和章节偏移必须一致。
- 实际解压采用 Node 异步 zlib 的输出预算，不用头部声明代替预算，也不回退 raw-deflate 或吞掉失败。
- UTF-16LE 严格解码，章节边界不可切开代理对；不修正错误偏移、不裁短正文、不用替换字符掩盖损坏。
- 解析进程只能读本次固定私有 bundle，无文件写权限，不继承模型密钥；有超时、取消和 IPC 结果校验。这里的 Node permission 不是完整操作系统/网络沙箱。

## 兼容性边界

当前候选从文字型、多章、正文索引、PNG/JPEG封面开始。漫画型、混合型、其他图片和未知字段仍在第二阶段研究范围内，未验证前拒绝而非静默丢内容。自造 fixture 与原版读取链路测试不冒充独立真实 UMD 文件验收。

原件与派生 EPUB 的内部双份存储、转换器版本及双哈希关系已在本文最后一批完成；生产化仍需要公开导入/阅读UI、知识来源/回跳闭环、更多合法真实样本与浏览器验证。不得仅将 `.umd` 加入扩展名白名单。

## 2026-09-20 候选代码与首轮门禁

- `umd-container.ts` / `umd-parser.ts`：文字型结构预检、索引顺序、长度/UTF16/受限异步解压；`umd-worker*.ts`：固定私有子进程、超时/取消/IPC校验，禁止写文件。
- `umd-epub.ts`：EPUB2/NCX、固定ID/路径/ZIP时间、正文XML转义、封面完整解码、生成前预算及生成后EPUB安全预检。
- `umd-conversion.ts`：受控装配解析与生成，返回原件哈希、派生物哈希、转换器版本和章节范围；不向生产数据库保存任何内容。
- 发现既有 EPUB 提取器会二次解码部分字面实体、给 `&gt;` 补空格，并过滤与章名同文的段落。未修改旧算法/旧锚点；新增 UMD 精读投影直接使用严格解码的同一快照，DOM Range 回跳验证包含字面实体、HTML样式文本、与标题同文段落。
- 当前自造样本经过真实受限子进程、EPUB生成及旧EPUB读取兼容检查；原件字节没有覆盖。生成 EPUB 另在隔离生产 API 导入成功，两章、下载字节与生成哈希一致。这不是 UMD 原件/派生版双份持久化已完成的证明。
- 全量首轮165文件2342项通过，包含本地真实 EPUB/PDF 回归，无跳过。构建与定向工具检查记录见本地 `.verify-umd-*.log`。

## 2026-09-20 双份持久化内部闭环（尚未开放上传）

- 新增 `umd-import.ts` 组合根：严格转换并核对输入快照后，先不可覆盖地保存 UMD 原件和派生 EPUB，再用一个 SQLite 事务写书籍、版本、正文及转换关系。转换失败不写书库；正常事务失败或取消只清理本次发布的文件，绝不删除已有同名文件。
- 原件保留 `originals/<editionId>.umd` 及原始 SHA-256；派生物保存到 `derived/<editionId>.epub`，独立记录文件哈希、大小、转换器版本 `umd-epub-v1` 和连续 UTF-16LE 章节来源区间。派生哈希不会覆盖原件身份。
- 新增 `edition_conversions` 表及无损 schema v2 升级。合法旧记录逐列复制；不合法旧记录使整体升级回滚，不能过滤掉坏记录后声称升级成功。旧正文、标注和对话不重写。
- 回滚本身失败意味着提交状态未知：保留已发布文件并聚合报告错误，避免删除可能已被提交记录引用的文件。没有声称已实现断电恢复或自动孤儿清理。
- 新增只读 `/api/books/:bookId/converted?editionId=...`：绑定书籍和版本，核对来源、两份固定路径、两个文件的大小和哈希；跨书版本拒绝，丢失/损坏有明确错误。下载保持 attachment、sandbox CSP、nosniff、no-store。原件接口仍返回 UMD 原始字节。
- 书库与书籍 API 仅公开转换格式、来源哈希、派生哈希、大小、转换器版本和时间；内部磁盘路径与来源区间不返回客户端。旧版本没有 conversion 字段时仍兼容。
