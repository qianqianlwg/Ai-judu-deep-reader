# 按句意细读与本节句读（2026-09-29）

## 已实现范围

- 顶部“句读 · 选项”默认“按句意细读”，可切换“整段句读 · 原有”；两种模式均由 Agent 按工具描述判断组合，句子或自然段只是最小单位。偏好保存在本机浏览器，无模式字段的旧接口请求仍保持兼容。
- 目标原文直接交给 Agent，由它确定连续语义块。程序不按句号、固定字数或嵌入相似度代替语义判断。
- 优先提交块末尾逐字引文和段落 ID，程序按原文顺序解析精确 UTF-16 范围；亦兼容完整逐字 fragments。重复结尾不猜首个命中，要求模型消歧；核验连续覆盖、顺序、字符边界与长度。
- Agent 可将直白或纯图注等内容标为 skip，但必须给出原因并保留完整来源。界面称“略过”，不产生解释标注，用户可点“仍然句读”。
- 每块独立保存助手消息、来源、结果及标注；父消息保存整个任务。会话展示聚合子消息，知识记录仍保留独立身份。发布使用事务和 attemptId 写入栅栏。
- 失败/停止保留完成块，继续时复用计划、只执行未完成块。刷新后可恢复。首版不承诺关闭页面后持续后台执行。
- 每块提供定位原文、追问此块、重新句读；引用依据可展开。首次选择短句不必凑够原有整段流程的10字下限。
- 本节入口位于精读标题与工具栏；原版通过外部覆盖层在标题旁显示，空间不足或定位不可靠时使用工具栏。原书 DOM、CFI、shadow root、安全策略不改变。

## 明确边界

- “本节”目前对应已经导入的 chapter 正文范围。适用于目录小节与 chapter 一致的书籍；任意正文内层小标题、跨 EPUB 文件的父节树尚未实现，不能声称所有视觉小标题都能识别。
- PDF/CBZ 不把页面当小节。其他格式只使用已有可核验文字范围；不做 OCR、不解读图片，弹窗明确提示。
- 单次本节最多30000字符、256段；计划最多128块（结构化结果的资源保护上限），不做分块字数或句数的语义判定。超限明确拒绝，不静默截断。
- 模型必须支持工具调用。计划最多修正三次，缺工具或不完整输出明确失败；不会把普通 Markdown 当作可靠分块。
- 生成按块串行。任务 Token 安全预算和现有请求超时可中断大任务，完成块保留，可继续；没有无限并发。
- 重新句读创建新结果，旧记录保留；没有自动把旧整段解释拆成句群。重复的同会话本节入口打开已有任务。
- 本轮只使用本地模拟模型验证协议、保存、流式显示和交互；真实模型的语义质量、耗时、消耗需要实际使用评估。

## 设计决策

- 被否决：程序预分句后让模型组合、按固定字数截断、用一篇总结冒充多个精确来源、把长解释插入原书改变分页、把略过算作已解释。
- 采用：Agent 直接判断，程序验证来源；父任务聚合多个独立可恢复结果；有限范围先交付，不清库、不重写旧段落 ID。
