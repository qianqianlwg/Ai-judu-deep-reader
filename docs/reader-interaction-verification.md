# 阅读交互修复与验收

## 本轮范围

1. 正文可用区域止于底部选区栏之前；按浏览器实际字体、标题与段落高度分页。
2. 阅读锚点仅由主动翻页／定位更新；字号、窗口尺寸往返不覆盖锚点。
3. 概念词、句末历史图标分别打开独立说明。句读只加下划线；浮层由 portal 承载并测量边界。
4. 请求首次即固定 thread/user/assistant ID。失败、刷新重试复用原消息及输入快照。
5. 每条新消息附当次选文和原文定位入口；不会拿当前选区冒充历史原文。
6. 本书知识卡片汇集所有会话的概念与有效句读；书级字典使无当前标注的段落也显示真实概念词。
7. 聊天手动滚动后停止跟随；历史定位仅执行一次；“回到最新消息”直接到真实底部。

## 自动回归

- 单元与 DOM 测试：实测分页边界、UTF-16 完整覆盖、缩放往返、概念跨页、重叠标注、浮层 resize/scroll/Esc、会话恢复、最近阅读切书锁、知识刷新、聊天滚动意图。
- 协议集成：OpenAI／Claude SSE、首条失败与刷新重试、幂等写入、旧请求竞争、空输出与中途断流、上下文快照。
- 本地真实 EPUB：通过 EPUB_FIXTURE_DIR 显式开启；不把书籍放入仓库。
- 全量 lint、严格类型检查、生产 build。

## 浏览器验证记录

隔离端口 3241、3243，独立构建目录及独立 SQLite，模型由本机 3242 故障模拟服务提供；没有调用真实付费模型进行故障注入。

- 测试书第二页原文偏移 472：字号连续缩小两次、再放大两次后，页首及整页文字完全一致。
- 窗口从 1280×720 缩到 950×450：正文末端未越过选区栏；浮层保持窗口内，锚点离开可见页时关闭。还原后回到偏移 472。
- 用户提供的真实书籍 2082 段完成全书分页；长章节页的正文末端位于选区栏之上。
- 首次请求故意返回 503，刷新后重试：user/assistant 两个 ID 不变，消息数仍为 2；原文卡片仍在。
- 历史消息定位后点击“回到最新消息”：scrollTop=1666、最大值=1666；随后手动上滚可停在历史位置。
- 概念“自我意识”展示该词定义；句末图标展示历史句读。无 annotation 的段落仍能通过书级词典命中旧概念“独立性”。
- 知识卡片提供概念和句读记录 tabs，可跨页定位原文及打开关联对话。

## 诚实边界

旧消息缺少准确原文位置时明确禁用原文跳转，不从线程最后选区或模型概括猜位置。旧概念只要有已保存名称，仍可逐字匹配；无定义时显示“暂无定义”。

pgvector 仅有可选迁移和查询适配；当前导入没有自动生成并写入向量。真实向量索引建设、Codex 专有压缩协议不属于本轮完成结论。不得把这些测试当作第三阶段所有长期目标的完成证明。
