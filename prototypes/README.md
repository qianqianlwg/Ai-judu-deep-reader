# 句读回答呈现对照原型（2026-09-22）

打开 `reading-answer-presentation-compare.html`，或使用任务内嵌预览。HTML 无外部依赖、无 API 请求，不读取正式书籍和标注。

## 对比范围

- A：普通排版，作为基线。
- B：关键词彩色字、关键句深绿字与细下划线。
- C：关键词浅黄底色、关键句浅绿行内底色。
- D：彩色关键词、一块主旨底色、按需展开的概念与依据。
- 论述和文学两段自制示例；同一示例的四种方案共享完全相同的正文。
- 单方案预览、四方案并排、字号与强调开关；有宿主设计工具时使用宿主控件，无支持时保留本地控件。
- 所有引用均明确为自制示例，不伪造真实书籍页码和跳转。
